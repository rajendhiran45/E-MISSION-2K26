## 📌 About

**E-MISSION 2K26** is the official website for the **19th State Level Technical Symposium** organized by the **Department of Electronics and Communication Engineering (ECE)**, **M.A.M. College of Engineering**, Siruganur, Tiruchirappalli.

The website provides participants with complete event information, registration access, schedules, venue details, and an interactive gallery through a modern, responsive interface.

---

## ✨ Features

* 🎓 Modern and responsive design
* 📱 Mobile-friendly user interface
* 📅 Symposium event information
* 🏆 Technical & Non-Technical events
* 📝 Online registration with QR Code
* 🖼️ Event gallery
* 📍 Venue and contact details
* ⚡ Fast loading performance
* 🌐 Progressive Web App (PWA) support

---

## 🛠️ Tech Stack

* HTML5
* CSS3
